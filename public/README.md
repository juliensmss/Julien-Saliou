# Dossier Public - Assets du Portfolio Julien Saliou

Vous pouvez déposer manuellement vos photos dans ce dossier pour remplacer les images par défaut du portfolio.

## 📁 Noms de fichiers acceptés et recommandés

Pour chaque projet, déposez une image portant le nom exact indiqué ci-dessous (au format `.jpg` ou `.png`). L'application détectera automatiquement vos fichiers locaux !

* **ExxonMobil** : Déposez un fichier `exxonmobil.jpg` (ou `exxonmobil.png`)
* **EDF (Nucléaire)** : Déposez un fichier `edf.jpg` (ou `edf.png`)
* **Les Grands Chais de France (IoT)** : Déposez un fichier `lgcf.jpg` (ou `lgcf.png`)
* **Danone Pays de Bray (MES/OEE)** : Déposez un fichier `danone.jpg` (ou `danone.png`)
* **TotalEnergies (ISO 50001)** : Déposez un fichier `totalenergies.jpg` (ou `totalenergies.png`)
* **Brasserie B&B (Flux Logistique)** : Déposez un fichier `log-brewery.jpg` (ou `log-brewery.png`)
* **Aéronautique (Six Sigma)** : Déposez un fichier `six-sigma.jpg` (ou `six-sigma.png`)
* **Junivers (IA/Socio-Psycho)** : Déposez un fichier `junivers.jpg` (ou `junivers.png`)
* **Bayer & Syensqo (Expertise SEC-AFI)** : Déposez un fichier `strategy-bayer.jpg` (ou `strategy-bayer.png`)
* **Thales (MES/Défense)** : Déposez un fichier `mes-thales.jpg` (ou `mes-thales.png`)

## 💡 Comment faire l'upload manuellement ?

1. Dans la colonne de gauche de l'éditeur de code, vous voyez maintenant le dossier **`public`**.
2. Glissez-déposez l'image que vous souhaitez de votre ordinateur directement dans le dossier **`public`**.
3. Renommez le fichier téléchargé en fonction du projet (ex: `exxonmobil.jpg` pour le projet ExxonMobil).
4. Le portfolio mettra instantanément à jour l'image en direct ! Si le fichier est absent ou corrompu, le site affichera par défaut une superbe photo d'Unsplash de secours.
